# 🏥 물리치료 4-에이전트 주간 뉴스 자동화 시스템

국내외 물리치료 업계 전반(정책·법률, 임상·연구, 글로벌 논문)의 뉴스를 자동으로 수집하고, **매주 3세트의 쇼츠 영상 대본(TTS 음성 포함)과 인스타그램 고화질 카드뉴스(PNG 이미지)**를 마우스 클릭 없이 일괄 자동 생성하는 파이프라인입니다.

---

## 👥 4대 에이전트 협업 체계

```text
[Agent 1. 리서처] ──▶ 3대 카테고리별 뉴스 수집 (국내 정책 1세트, 국내 임상 1세트, 해외 논문 1세트)
        │
        ├──▶ [Agent 2. 카드 작가] ──▶ 6장 캐러셀 카드뉴스 텍스트 & 해시태그 기획
        │
        └──▶ [Agent 3. 쇼츠 감독] ──▶ 40초 숏폼 대본, 3초 훅, B-roll 연출 지시문 작성
                │
                ▼
        [Agent 4. 감수관]   ──▶ 의료법 위반 표현 완화 & 법적 안전 고지문 부착 및 승인
                │
                ▼
        [자동 렌더링 엔진] ──▶ 1080x1350 카드뉴스 PNG 6장 + Edge-TTS 나레이션 MP3 자동 생성
```

1. **Agent 1 (뉴스 큐레이터)**: 치료법에 한정하지 않고 법, 보험, 수가, 해외 논문, 신기술 등 물리치료 산업 전반의 뉴스를 탐색하고 이전 주와 겹치지 않는 3개 세트를 엄선합니다.
2. **Agent 2 (카드뉴스 카피라이터)**: 1080x1350 규격에 최적화된 6장 슬라이드 텍스트와 인스타그램 캡션을 작성합니다.
3. **Agent 3 (쇼츠 비디오 디렉터)**: 40~45초 동안 시청자를 사로잡는 타임코드별 3초 훅, 화면 연출 큐, TTS 나레이션 대본을 작성합니다.
4. **Agent 4 (의료/법률 감수관)**: 과장 광고 표현(완치, 기적 등)을 완화하고 주의사항 디스클레이머를 부착하여 최종 승인합니다.

## 📁 결과물 폴더 구조

`python main.py`를 실행하면 매주 해당 연도-월-주차(예: `2026년 9월 1주차`) 폴더에 아래와 같이 산출물이 자동 정리됩니다:

```text
output/
└── 2026년 9월 1주차/
    ├── 주간_스크랩_출처_및_원문링크.md       # 3개 세트 전체 기사 출처 및 원문 링크 총정리
    ├── set1_국내정책_보험/
    │   ├── cards/                          # 인스타용 1080x1350 PNG 이미지 6장
    │   │   ├── card_01.png (표지)
    │   │   ├── card_02.png (뉴스 01)
    │   │   ├── card_03.png (뉴스 02)
    │   │   ├── card_04.png (뉴스 03)
    │   │   ├── card_05.png (전문가 인사이트)
    │   │   └── card_06.png (아웃트로)
    │   ├── shorts/
    │   │   ├── shorts_video.mp4            # 배경 모션 완성본 쇼츠 영상 (1080x1920)
    │   │   ├── narration.mp3               # 한국어 AI 아나운서 음성 파일
    │   │   └── shorts_storyboard_guide.txt # 화면 연출 큐 & 대본 전문
    │   ├── sources_and_links.md            # 해당 세트 스크랩 출처 및 원문 링크
    │   └── instagram_caption.txt           # 복사해서 붙여넣는 인스타 본문 & 해시태그
    ├── set2_국내임상_연구/
    └── set3_해외동향_논문/
```

## 🚀 빠른 시작 가이드

### 1. 환경변수 설정 (선택 사항)
`.env.example` 파일을 복사하여 `.env` 파일을 만들고, Google Gemini API 키를 입력합니다:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```
*(※ API 키가 없어도 내장된 검증용 고품질 물리치료 브리핑 데이터로 즉시 동작합니다.)*

### 2. 실행 및 SNS 자동 업로드 가이드

#### ① 일반 실행 (콘텐츠 3세트 전체 렌더링)
```bash
python main.py
```
실행 즉시 `output/{연도}년 {월}월 {주차}/` 폴더에 3세트(카드뉴스 18장, 쇼츠 MP4 3편, AI 음성, 출처 문서 등)가 일괄 자동 생성됩니다.

#### ② 인스타그램 1회 로그인 세션 설정
Playwright 브라우저를 띄워 인스타그램에 로그인하고 세션(`assets/instagram_session.json`)을 안전하게 저장합니다:
```bash
python main.py --login-insta
```
*(최초 1회만 완료하면 이후에는 백그라운드에서 무인 자동 실행됩니다.)*

#### ③ 유튜브 Data API v3 1회 OAuth 인증 설정 (선택 사항)
Google Cloud Console에서 발급받은 `client_secrets.json`을 `assets/` 폴더에 넣은 후 실행합니다:
```bash
python main.py --auth-yt
```

#### ④ 콘텐츠 생성 + SNS 원클릭 자동 업로드 (예약 발행 & 첫댓글)
```bash
# 인스타 예약 + 유튜브 쇼츠 동시 업로드 & 첫댓글
python main.py --upload

# 인스타그램 4:5 6장 캐러셀 예약 업로드만 실행
python main.py --upload-insta

# 유튜브 쇼츠 업로드 및 첫댓글만 실행
python main.py --upload-yt
```

## 💬 첫댓글 및 예약 발행 전략

1. **인스타그램 캐러셀 예약 공개 (Scheduled Post)**:
   * 인스타그램 웹의 `고급 설정` ➔ `이 게시물 예약`을 통해 치료사들이 퇴근 후 가장 활발히 피드를 확인하는 **저녁 8:00 (또는 설정 시간)**으로 자동 예약됩니다.
   * 예약 게시물 특성에 맞춰, 본문 캡션 하단에 **[💬 치료사 한마디 & 출처 안내]** 전용 첫댓글 블록을 자동 병합하여 참여를 유도합니다.
2. **유튜브 쇼츠 첫댓글 자동 고정**:
   * 영상 업로드 즉시 `commentThreads().insert()`를 호출하여 타임스탬프와 임상 토론 질문이 담긴 첫댓글을 자동으로 등록합니다.
